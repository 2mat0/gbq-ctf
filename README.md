# gbq-ctf

Repository for **Google Beginner's Quest CTF** write-ups.

This repo contains challenge solutions and write-ups organized by category. Each folder corresponds to a CTF challenge category and holds the relevant write-ups and solve scripts.

## Categories

| Folder | Description |
|--------|-------------|
| [crypto](./crypto) | Cryptography challenges |
| [misc](./misc) | Miscellaneous challenges |
| [net](./net) | Networking challenges |
| [pwn](./pwn) | Binary exploitation challenges |
| [rev](./rev) | Reverse engineering challenges |
| [web](./web) | Web exploitation challenges |
